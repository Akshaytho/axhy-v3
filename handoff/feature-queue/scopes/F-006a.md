## 1. Purpose

When a SUPERVISOR-role user OTP-verifies, the existing OTP flow stores tokens and routes to `/(supervisor)/profile`. F-006a wraps this with:

1. JWT-scoped role check (reject non-SUPERVISOR `memberships[0]` with a typed error).
2. After-token-persistence call to `OneSignal.login(external_id = User.id)` — for F-011's adapter to target.
3. Pre-prompt explainer modal → OS push permission prompt → exactly-once navigation.
4. Sign-out call to `OneSignal.logout()` BEFORE `clearTokens()` (prevents phantom subscription leak on same-device user switch).
5. Cold-start re-link: on app launch with existing tokens, re-fire `OneSignal.login()` to re-link the device subscription.

All OneSignal calls are guarded by `shouldCallOneSignal()` — return `false` on web OR when `EXPO_PUBLIC_ONESIGNAL_APP_ID` is undefined. Auth flow always succeeds; OneSignal is the optional bit.

## 4. Verification

**Unit tests** (mock OneSignal SDK + mock auth-store; mock `Platform.OS` + `process.env.EXPO_PUBLIC_ONESIGNAL_APP_ID`):

- `apps/mobile/lib/identity-lifecycle.test.ts` — **10 cases:**
  1. **happy path:** `memberships = [{role: 'SUPERVISOR', companyId: A}, {role: 'WORKER', companyId: B}]` → persists tokens + calls `OneSignal.login(userId)`.
  2. **logout ordering:** `onAppLogout()` calls `OneSignal.logout()` BEFORE `clearTokens()` (assertion order).
  3. **cold-start re-link:** `onColdStartReady(tokens)` decodes JWT + calls `OneSignal.login(userId)` exactly once.
  4. **logout timeout:** `OneSignal.logout()` >3s → falls through to `clearTokens()`; logout still succeeds.
  5. **JWT decode failure:** corrupt JWT → warning logged + skip OneSignal.login + setTokens still succeeds.
  6. **web platform no-op:** `Platform.OS === 'web'` → setTokens succeeds + OneSignal call skipped + warning.
  7. **no App ID no-op:** `EXPO_PUBLIC_ONESIGNAL_APP_ID` undefined → same auth-successful, OneSignal-no-op.
  8. **mismatched-order reject:** `memberships = [{role: 'WORKER'}, {role: 'SUPERVISOR'}]` → throws `NonSupervisorRoleNotSupportedError`; no setTokens, no OneSignal call.
  9. **no-SUPERVISOR reject:** `memberships = [{role: 'WORKER'}]` → same throw. Also covers empty `memberships = []`.
  10. **defensive cold-start logout:** `onColdStartReady` with stored `activeRole !== 'SUPERVISOR'` → `onAppLogout()` + routes to `/(auth)/phone`.

- `apps/mobile/components/PushPermissionPrompt.test.tsx` — **5 cases** (exactly-once nav across all prompt branches): Continue+grant / Continue+deny / Decline / `requestPermission` throws / web-or-no-App-ID skip. Each asserts `router.replace` called exactly once.

**Total: 15 unit cases across 2 files.** All pass via `pnpm --filter mobile test`.
