Rendering: this HTML runs Mermaid via the jsdelivr CDN. Where it reliably renders: any local browser, any static-file server (e.g. python3 -m http.server), GitHub Pages, Vercel/Netlify static deploy. Where rendering is NOT assumed: raw GitHub web view of the HTML file (GitHub blob view doesn't reliably execute the module-script that loads Mermaid).
