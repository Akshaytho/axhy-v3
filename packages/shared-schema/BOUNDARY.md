# @axhy/shared-schema — BOUNDARY

## Owns
- Prisma schema (the single source of truth for the database)
- Zod schemas for every domain entity
- Shared TypeScript types
- OpenAPI generation from Zod schemas
- DPDP `@personal` annotations on personal-data fields

## Does NOT own
- Business logic
- Database queries (those live in `apps/backend`)
- HTTP routing
- AI prompts

## Internal dependencies
**ZERO.** This is the seed package. It must not import from any other internal package.

## External dependencies
- `zod` — schema validation
- `@prisma/client` — generated by Prisma at build time

## Who imports this
- `@axhy/state-machines`
- `@axhy/business-rules`
- `@axhy/ai-tools`
- `@axhy/api-client`
- `apps/backend`
- `apps/admin-web`
- `apps/mobile`
