# @axhy/api-client — BOUNDARY

## Owns
- Auto-generated typed HTTP clients from backend OpenAPI spec
- TanStack Query hooks for every endpoint
- Request/response types (re-exported from `@axhy/shared-schema`)
- Auth token injection on every request

## Does NOT own
- API logic (lives in `apps/backend`)
- Business decisions
- UI

## Internal dependencies
- `@axhy/shared-schema`

## Who imports this
- `apps/admin-web`
- `apps/mobile`

## Generated content
`src/generated/` is regenerated by `pnpm generate` against backend OpenAPI spec. Do not hand-edit.

## Lineage anchor
ADR-0011 — Generated typed clients over hand-written fetch.
