# 02 — Walk log (real taps only, no shortcuts — needing one = bug)

One block per step, per persona, in walk order. EVERY block gets its own timestamp.

```
## Step <n> — <screen/action> — as <persona>
- At: YYYY-MM-DD HH:MM IST
- Becoming them: <one line of their situation/feeling at this moment>
- UI: what the screen showed (screenshot ref) — every button real? every word/number true?
- Route: request + response observed
- DB proof: tables checked, rows shown (query + result), missing/null values?
- Side-effects: audit row? outbox row? notification row?
- Verdict: PASS / FAIL → bug #__ in 03-bugs.md
```
