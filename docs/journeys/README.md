# Persona journeys

Four personas × twelve workflows = forty-eight journey docs. Each one walks an end-to-end user flow as the persona experiences it.

## Personas

- **Mr. Reddy** — owner of Surya Cleaning (80 workers, 6 supervisors, 12 sites)
- **Kavitha** — HR manager at Surya Cleaning
- **Ravi** — supervisor at Surya Cleaning
- **Suresh** — worker at Surya Cleaning

## Workflows (12, master plan §O)

1. Worker onboarding (Suresh joins)
2. Daily shift (worker view)
3. Daily shift (supervisor view)
4. Voice change capture (supervisor)
5. Shift swap / replacement
6. Photo + voice verification
7. Flagged-visit review
8. End-of-day summary
9. HR rule update + acknowledgment
10. Leave request + approval
11. Payslip generation + delivery
12. Tenant onboarding (founder + owner)

## Format

Each journey doc has:
- Persona at the top
- Trigger (what starts the flow)
- Step-by-step in plain English
- Screens + APIs + state transitions per step
- Audit events fired
- Notifications sent
- Edge cases observed in real cleaning operations

Journeys land Day 5 of evidence sprint.
